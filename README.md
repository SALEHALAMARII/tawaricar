## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الجذر مباشرة).
2. Settings → Pages → Deploy from branch، واختر الفرع الرئيسي والجذر `/`.
3. الملف `CNAME` يحتوي `tawaricar.com`.
4. اربط الدومين من DNS في Hostinger حسب تعليمات GitHub Pages الحالية للدومين المخصص، ثم فعّل Enforce HTTPS بعد نجاح التحقق.
5. لا تحذف `.nojekyll`.

## بعد النشر
- أضف Domain Property في Google Search Console.
- أرسل `https://tawaricar.com/sitemap.xml`.
- اربط GA4 عند توفر Measurement ID. الكود الحالي يجهز أحداث `click_call` و `click_whatsapp` ويعمل تلقائيًا عند إضافة gtag.
- أنشئ Google Business Profile حقيقيًا كنشاط Service Area Business إذا كانت الشروط التشغيلية متوافرة، بدون فروع أو عناوين وهمية.

## الصور
الصور المرفقة صور توضيحية مولدة للاستخدام البصري، وليست توثيقًا لأعمال منفذة فعليًا. استبدلها تدريجيًا بصور حقيقية للفريق والأعمال، مع الاحتفاظ بأسماء الملفات أو تحديث الـHTML.

## ملاحظات SEO ثابتة
- 36 صفحة `index,follow` وSelf Canonical.
- لا صفحات أحياء، ولا صفحات لكل تهجئة، ولا Blog عند الإطلاق.
- الاتصال هو CTA الأساسي والواتساب ثانوي.
- لا أسعار أو زمن وصول أو تقييمات أو عناوين وهمية.
- السحب الثقيل والهيدروليك غير معلنين كخدمات أساسية.
